## Todoist

### 产品概况

| 属性 | 详情 |
|------|------|
| **公司** | Doist Inc. |
| **上线时间** | 2007年 |
| **总用户数** | 4700万+ (2025) |
| **定价** | 免费 / Pro $4/月 / Business $6/月 |
| **平台** | 全平台（Web, iOS, Android, Windows, Mac, 浏览器插件） |

### 核心功能

- 任务管理（项目、标签、优先级、截止日期）
- 自然语言输入（如"明天下午3点开会"）
- 跨平台同步
- 协作功能（共享项目、分配任务）
- 生产力可视化（Karma积分、完成趋势）
- 模板系统
- AI助手（Todoist AI）

### 局限性（对拖延症用户）

1. **仅记录不干预**：帮助记录任务但不帮助用户开始执行任务
2. **提醒无效**：对真正拖延的用户，提醒往往无效甚至产生压力
3. **缺乏情感支持**：纯工具属性，缺乏情感陪伴和鼓励
4. **任务拆解有限**：虽有子任务功能，但缺乏智能拆解

## 滴答清单 (Dida365 / TickTick)

### 产品概况

| 属性 | 详情 |
|------|------|
| **公司** | 杭州随笔记网络技术有限公司 |
| **上线时间** | 2013年 |
| **主要市场** | 中国及海外市场 |
| **定价** | 免费 / 高级版约¥139/年 |
| **平台** | 全平台 |

### 核心功能

- 任务管理与日历视图
- 番茄钟（内置Pomodoro计时器）
- 习惯追踪
- 白噪音
- 智能清单（按时间、标签筛选）
- 跨平台同步
- AI功能（智能日期识别等）

### 与AI4ADHD的对比

| 维度 | 滴答清单 | AI4ADHD (目标定位) |
|------|---------|-------------------|
| **核心定位** | 任务管理工具 | AI陪伴型效率助手 |
| **任务拆解** | 手动子任务 | AI智能拆解+建议 |
| **情感支持** | 无 | 核心功能（鼓励、共情） |
| **开始成本** | 用户自行决定 | AI主动降低启动成本 |
| **交互方式** | 表单输入 | 对话式自然交互 |
| **游戏化** | 基础（习惯打卡） | 深度（积分、贴纸、等级） |
| **价格预期** | ¥139/年 | ¥11-19/月 |

## 市场空白分析

1. **记录vs执行鸿沟**：现有工具解决"记什么"但不解决"怎么开始"
2. **AI整合浅层**：虽有AI功能，但主要限于日期识别，未深度介入行为改变
3. **情感缺位**：缺乏对拖延症用户的情感理解和支持
4. **中国本土化不足**：海外产品本土化有限，国内产品功能同质化
