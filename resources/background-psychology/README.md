## 🔑 写作建议

### 引用密度建议

每个 paragraph 引用 3-5 篇关键文献，避免堆砌。

### 数据点（直接可引用）

- 拖延流行率：77.6%（医学生中-高度拖延，2025）、50%（大学生慢性拖延，Klingsieck 2013）
- ADHD 流行率：3-5% 成人、2-12% 高校生（Nugent 2014）
- iCBT 完成率：仅 34-36%（Mutter 2023）
- 拖延神经基础：dlPFC、paraPHC、vmPFC 灰质体积（Wang 2022, Liu 2019）

### 关键论述链

```
拖延的普遍性（数据）
  → 拖延的心理代价（焦虑-倦怠循环）
    → ADHD 群体的特殊困境（执行功能 + 情绪调节缺陷）
      → 神经基础（前额叶-边缘系统失衡）
        → 现有干预的失效（CBT 可及性、Pomodoro 刚性、App 缺乏循证）
          → AI Agent 个性化辅助的必要性
```

### 与本项目设计的对应

| 文献证据 | 项目设计回应 |
|---------|-------------|
| 拖延即情绪调节失败（Pychyl, Eckert） | AI Agent 提供情感陪伴 |
| ADHD 任务启动困难（Sæle, Barkley） | AI Agent 主动构建任务、自动分解 |
| iCBT 完成率低（Mutter, Idrees） | 自然对话式 UI 降低参与门槛 |
| 番茄法刚性（Renacido） | 个性化任务粒度由 AI 推荐 |
| ADHD App 缺乏循证（Păsărelu） | 设计基于学术文献的功能 |
| 时间感知缺陷（Seesjärvi, Liu） | 任务可视化 + 截止日期提示 |
| Zeigarnik 效应（James, Wendsche） | 持久化任务清单作为认知卸载 |
| 工具单一性问题（Hu） | 多视图（项目、任务、标签）适配不同用户 |
